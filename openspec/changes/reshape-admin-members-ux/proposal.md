# Reshape Anggota filters and invitations

## Why

At phone width the advanced filter drawer presents small, uneven selector triggers. The directory heading needs more separation, and the preview only offers a generic invitation placeholder even though the production page has invitation status and a multi-step invite flow.

## Scope

Use the approved admin visual system to give advanced filters a consistent full-width form layout, improve section spacing, and add synthetic invitation list and invite form/review/result states. Mirror the production single/bulk invitation, searchable komsat, status, and confirmation concepts without API calls.

## Acceptance

- Advanced filter controls are uniform, readable, and touch-sized on phones.
- Directory heading has clear separation from the page header and filter toolbar.
- Invitation status is reachable; invite action leads through form, review, and result.
- All sample content remains synthetic and the preview gate passes.
