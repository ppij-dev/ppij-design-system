# Brand

- **Name**: PPIJ, Persatuan Pelajar Indonesia di Jepang
- **Primary color**: PPIJ red, `#C8102E`
- **Type**: Plus Jakarta Sans, with Noto Sans JP for Japanese text
- **Icons**: Tabler icons only. Never use a text glyph as an icon.
- **Language switch**: a quiet text action or a labelled menu. Never isolated
  boxed EN or ID codes as a primary button.
- **Typography law**: admin typography equals portal typography. Same
  families, same scale.

The logo file and the full usage rules live in the `brand/` folder of the
repository. Token values on the Colors page are the binding values.

## Pedoman Identitas Visual (logo)

Pedoman pemakaian logo PPI Jepang disusun Biro Pendataan: susunan vertikal dan
horizontal, variasi warna Primer, Inversi Hitam dan Inversi Putih, aturan latar
gelap, ruang bebas, larangan, tipografi, dan berkas SVG yang bisa diunduh.

**Status: usulan untuk AD/ART 2027-2028.** Variasi Inversi dan susunan
horizontal belum disahkan Kongres. Sampai disahkan, surat dan dokumen resmi
memakai versi Primer, dan aturan di halaman Logo tetap berlaku.

Merah logo (`#ED2326`, ART Pasal 55) adalah warna logo dan blok warna besar.
Merah antarmuka `#C8102E` di atas tetap dipakai untuk teks, tautan, dan tombol,
karena merah logo hanya 4,3:1 di atas putih.
